# SSP Ledger

SSP Ledger is a web application designed for Service Providers (SSPs) to manage and track their records. It features role-based access for SSPs and Admins, providing a secure and efficient way to handle data.

## Features

- **User Authentication**: Secure login and registration system.
- **Role-Based Access**: Separate dashboards and functionalities for SSPs and Admins.
- **SSP Dashboard**: Visual representation of records and data.
- **Record Management**: Add, view, and manage records with ease.
- **Admin Dashboard**: Tools for user and record management.

## Technologies Used

- **React**: A JavaScript library for building user interfaces.
- **Vite**: A fast build tool and development server.
- **TypeScript**: A typed superset of JavaScript.
- **Tailwind CSS**: A utility-first CSS framework.
- **React Router**: For routing and navigation.
- **Axios**: For making HTTP requests.
- **Recharts**: For creating charts and graphs.
- **jspdf & xlsx**: For exporting data to PDF and Excel formats.

## Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

- Node.js (v14 or later)
- npm

### Installation

1. **Clone the repo**
2. **Install NPM packages**
   ```sh
   npm install
   ```
3. **Start the development server**
   ```sh
   npm run dev
   ```

The application will be available at `http://localhost:5173`.
